# The Critique Pass: Awwwards Rubric, Used to Catch Weak Work — Not to Chase a Look

Awwwards juries score submissions across four axes. Use the same four axes as an honest
pre-ship review, but keep in mind what this rubric is *for*: catching thin, underbaked work
before it ships — not steering every project toward the visual genre that wins Site of the
Day (dark backgrounds, oversized serif type, giant WebGL blobs). That genre is one valid
answer to the rubric, not the rubric itself.

## Design (visual craft)

Ask: does the typography, color, spacing, and imagery feel deliberate, or does it feel like
defaults? Check specifically for:
- A real type scale (not just three random font sizes), with at least one typographic
  choice that has a point of view rather than being interchangeable with any other project.
- Color used with intent — accents that mean something (state, hierarchy, brand) rather
  than decoration for its own sake.
- Spacing that's consistent with a system (a spacing scale, not eyeballed pixel values that
  drift between sections).

## Usability

Ask: could someone unfamiliar with the project actually use this without narration? Check:
- Primary actions are visually the loudest thing on the screen, not competing with
  decoration.
- Motion never blocks or delays the user from doing the thing they came to do (a scroll-
  jacked hero that takes 4 seconds to release the user is a usability bug wearing a design
  trend's clothes).
- Works with keyboard only and with `prefers-reduced-motion` on — see the non-negotiables
  list in the main SKILL.md.

## Creativity

Ask: if you removed the branding, could this be mistaken for a different, generic project?
If yes, that's the signal to push further, not to add another generic element in a
different color. Creativity here means a specific point of view about *this* brief — not
maximum novelty for its own sake. A simple, restrained design executed with unusual
precision can score higher on creativity than a chaotic one stacked with trend-of-the-month
effects.

## Content

Ask: does the design serve the actual content, or does the content feel like filler dropped
into a template? Lorem-ipsum-shaped copy blocks, generic stock-photo-style imagery, and
placeholder-looking icon grids are all signs the design was built before anyone thought
about what it needs to say.

## The unorthodox half of the mandate

After scoring honestly against the four axes above, ask one more question explicitly: is
there a convention being followed here purely out of habit — hamburger menu, centered hero,
three-card feature grid, footer with four link columns — that this specific brief would be
better served by breaking? Breaking convention should be a decision made *after* the
craft/usability/content bar is met, not a substitute for meeting it. Sloppy work with a
weird layout is not "unorthodox," it's just sloppy. Precise work that chooses not to look
like everything else is the actual goal.
